## Как устроен проект

Пять HTML-страниц соответствуют пяти частям задания. На каждой странице есть одинаковая навигация. Общий CSS хранится в `assets/css/styles.css`. В `assets/js/common.js` находится общая инициализация, а у каждой части есть свой JS-файл. Для простого статического сайта не нужны React, серверная часть или сборщик.

jQuery подключается из официального CDN. Используется полная версия 3.7.1: в slim-сборке нет необходимых эффектов. Атрибут `defer` позволяет сначала разобрать HTML; скрипты выполняются в порядке подключения. После библиотеки идут `common.js` и код страницы.

`$(document).ready(function () { ... });` запускает обработчик после готовности DOM. В консоли выводится точная строка `jQuery is ready!`. Это позволяет безопасно находить элементы и назначать события.

## Part 1 — Setup и selectors

Открой `index.html` и `assets/js/basics.js`.

- `$("#selector-title")` — поиск по уникальному ID.
- `$(".selector-copy")` — поиск по классу; результат может содержать несколько элементов.
- `$(".tag-demo").find("span")` — поиск элементов по тегу `span` внутри конкретного контейнера.
- `.text("...")` заменяет текст. Строка с `<strong>` будет отображаться как текст.
- `.html("...")` разбирает HTML-разметку. В примере создаётся настоящий элемент `<strong>`.
- `.css({ color: "#aa492c", fontWeight: "600" })` задаёт несколько стилей объектом.

Переменные с `$`, например `$title`, содержат объект jQuery. Это соглашение в именовании, а не требование JavaScript.

**Что попробовать изменить:** поменяй текст заголовка, цвет абзаца или добавь свой класс к выборке. Объясни, почему пользовательский ввод выводится через `.text()`, а не `.html()`.

## Part 2 — Effects

Открой `effects.html` и `assets/js/effects.js`.

`.hide()` скрывает элемент, `.show()` показывает, `.toggle()` переключает состояние. В задании есть отдельные кнопки для всех трёх методов.

`.fadeOut(400)` постепенно уменьшает прозрачность, затем скрывает элемент. `.fadeIn(400)` показывает элемент с плавным увеличением прозрачности. `.fadeToggle(400)` выбирает действие по текущему состоянию. Число 400 — длительность в миллисекундах.

`.slideUp(400)` сворачивает панель по высоте. `.slideDown(400)` разворачивает. `.slideToggle(400)` переключает состояние. В отличие от fade, slide меняет занимаемую высоту во время эффекта.

`.stop(true, true)` останавливает текущий эффект, очищает очередь и переводит текущий эффект к конечному состоянию. Поэтому быстрые повторные клики не создают длинную очередь. Второй аргумент `true` отличается от `false`: `false` оставляет текущие промежуточные значения.

Callback после эффекта обновляет подпись состояния. Это нужно делать после завершения эффекта, когда видимость уже соответствует результату.

**Что попробовать изменить:** увеличь длительность fade до 1000, поменяй содержимое панели, добавь ещё одну кнопку, скрывающую панель.

## Part 3 — DOM

Открой `dom.html` и `assets/js/dom.js`.

DOM — объектное представление HTML-документа. jQuery позволяет находить узлы, менять их и добавлять новые.

- `$("<li>").text(...)` создаёт новый элемент списка и задаёт безопасный текст.
- `.append(...)` вставляет элемент в конец контейнера.
- `.prepend(...)` вставляет в начало.
- `.children("li").last().remove()` удаляет последний непосредственный элемент списка.
- `.prop("disabled", true)` меняет текущее булево свойство кнопки. Когда список пуст, удаление отключается.
- `.attr("src", ...)` меняет путь к изображению. Одновременно обновляется `alt`, чтобы описание соответствовало картинке.
- `.attr("href", ...)` меняет адрес ссылки.
- `.val()` читает текущее значение поля формы.
- Событие `input` срабатывает при вводе, вставке и удалении текста. Поэтому оно подходит для живого предпросмотра лучше, чем только `keyup`.
- `$(this)` внутри обычной функции-обработчика обозначает элемент, который вызвал событие. Стрелочная функция имела бы другое поведение `this`.
- `event.preventDefault()` отменяет стандартную отправку формы. Данные не передаются на сервер.

`|| "Your name"` возвращает запасной текст, когда поле пустое. Превью использует `.text()`, поэтому HTML из поля не выполняется.

**Что попробовать изменить:** удаляй первый элемент вместо последнего; добавь третье изображение в массив; добавь поле города и его live preview.

## Part 4 — Animations

Открой `animations.html` и `assets/js/animations.js`.

`.animate(properties, duration, complete)` постепенно меняет числовые CSS-свойства. `left`, `top`, `width` и `height` без единиц трактуются как пиксели. `opacity` — число от 0 до 1.

У контейнера задано `position: relative`, у квадрата — `position: absolute`. Поэтому координаты квадрата считаются относительно контейнера. Установлены начальные значения: `left: 20`, `top: 20`, размер `64 × 64`, `opacity: 1`.

**Task 8:** один вызов меняет положение и увеличивает квадрат до `112 × 112`.

**Task 9:** четыре последовательных `.animate()` входят в стандартную очередь эффектов одного элемента: вправо, вниз, уменьшение до `36 × 36`, возврат ко всем начальным значениям. Это последовательность; каждый следующий шаг ждёт предыдущий.

**Task 10:** один вызов одновременно меняет координаты, размеры и прозрачность до `0.4`. Все перечисленные свойства меняются в течение одной анимации.

Конечные координаты рассчитываются по ширине и высоте контейнера. Квадрат не должен выходить за границы на телефоне. Кнопка Reset использует `.stop(true, false)` и `.css(original)`, чтобы остановить движение, очистить очередь и восстановить исходное состояние. При изменении размера окна примеры сбрасываются.

Базовый `.animate()` предназначен для числовых свойств. Для изменения цвета этим методом потребовалось бы дополнительное расширение; в проекте цвет задаётся через CSS.

**Что попробовать изменить:** сделай квадрат шириной 90, добавь пятый шаг в цепочку, измени непрозрачность на 0.7. Проверь, что Reset и границы продолжают работать.

## Part 5 — Gallery

Открой `gallery.html` и `assets/js/gallery.js`.

Выбран один мини-проект из задания — Image Gallery. Четыре локальных SVG-файла подключены обычными `<img>`. Кнопка Hide thumbnails запускает `.fadeToggle(300)` для миниатюр. `.promise().done(...)` ждёт завершения эффектов всей коллекции, затем обновляет подпись кнопки.

Каждая миниатюра хранит путь, название, описание и альтернативный текст в атрибутах `data-*`. Обработчик читает их через `.data()`, меняет `src` и `alt` большого изображения и открывает окно через `.fadeIn(250)`.

Индекс выбранной картинки хранится в `activeIndex`. Выражение `(index + length) % length` обеспечивает переход с последней картинки на первую и с первой на последнюю.

Диалог закрывается кнопкой, Escape или нажатием на фон. Стрелки переключают картинки. Фон становится `inert`, фокус остаётся внутри диалога, а после закрытия возвращается к выбранной миниатюре. Это делает галерею удобной при работе клавиатурой.

**Что попробовать изменить:** добавь пятую миниатюру и обнови подписи количества; замени одну иллюстрацию; измени длительность открытия.

## Частые вопросы

| Вопрос | Короткий ответ |
| --- | --- |
| Что делает `$()`? | Создаёт объект jQuery из селектора, DOM-элемента или HTML-строки; поддерживает также callback готовности. |
| Чем ID отличается от класса? | ID должен быть уникальным в документе; класс может повторяться. |
| `.text()` или `.html()`? | Первая работает с текстом, вторая разбирает разметку. Для пользовательского ввода используется `.text()`. |
| `.attr()` или `.val()`? | `.attr()` работает с HTML-атрибутами, `.val()` — с текущим значением поля. |
| Почему `.prop()` для disabled? | Это текущее булево DOM-свойство элемента. |
| Как назначается событие? | `$(selector).on("click", function () { ... });` |
| Fade или slide? | Fade меняет прозрачность; slide сворачивает и разворачивает высоту. |
| Как сделать анимации по очереди? | Несколько `.animate()` подряд на одном элементе. |
| Как сделать одновременно? | Несколько свойств в объекте одного `.animate()`. |
| Зачем `.stop()`? | Чтобы прервать движение и управлять накопленной очередью. |
| Что делает callback? | Выполняется после завершения эффекта или анимации. |
| Что будет без интернета? | CDN может не загрузиться; страница покажет сообщение об ошибке. Локальные изображения останутся доступны. |
| Где размещён сайт? | GitHub Pages, статические файлы из ветки main, папка root. |
| Зачем относительные пути? | Чтобы страницы и ресурсы работали внутри подпути репозитория на GitHub Pages. |
